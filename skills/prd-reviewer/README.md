
# 🔍 PRD Reviewer

### AI-Powered Product Requirements Review

A reusable AI skill designed to critically review Product
Requirements Documents from the perspective of an experienced
Product Manager.

Supports both traditional software products and AI-powered
product experiences.

## 🎯 What It Does

Evaluates PRDs across key product dimensions:

- **Product Strategy:** Problem clarity, user value, and business impact
- **User Experience:** User journeys, friction, and edge cases
- **Requirements:** Functional clarity and acceptance criteria
- **Success Metrics:** Outcomes, KPIs, and measurement strategy
- **Execution:** Feasibility, dependencies, and rollout readiness
- **AI Readiness:** Model reliability, evaluation, cost, and safety
  (when applicable)

## 🧠 How It Works

The skill first identifies the product type:

1. Traditional Software Product
2. AI-Assisted Product
3. AI-Native / Agentic Product

It then applies a context-appropriate review framework.

## 📋 Review Output

The reviewer produces:

1. Executive assessment
2. Product quality scorecard
3. Prioritized issues and recommendations
4. AI-specific assessment (if applicable)
5. Success metrics recommendations
6. Top recommended actions
7. Critical questions for the Product Manager

## 🚀 How to Use

The review instructions are defined in
[SKILL.md](SKILL.md).

Use the skill with a compatible AI agent, provide a PRD,
and ask it to evaluate the document.

The skill should distinguish confirmed issues from
missing information, assumptions, and potential risks.
